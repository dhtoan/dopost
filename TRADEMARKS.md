## If you fork dopost

Give your fork its own name and logo:

1. Replace the artwork in `assets/brand/` and `apps/web/src/lib/assets/favicon.svg`.
2. Replace the dopost name in the user interface, documentation and container image names.
3. Keep every licence notice. Renaming does not remove them: keep `LICENSE`, `NOTICE.md`, the files under `licenses/`, the copyright headers in source files and the statement that the code is based on OpenPost.

Instance owners who only want their own logo in the app can set it under Settings → Appearance → App branding. That is not a fork and needs no permission.
